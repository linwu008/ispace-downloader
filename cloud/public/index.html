第一次使用？查看注册与助手安装指南
  1. 注册官网账号

    填写自己的邮箱、8–128 位密码和邀请码。官网密码与学校密码互相独立。邮件找回暂未启用，请妥善保存密码。

  2. 下载 Windows 助手

    打开下载页，下载 ZIP 后完整解压，保留 _internal 文件夹，运行 CourseNestHelper.exe。不要在压缩包里直接运行。支持 Windows 10/11 x64，需要 Edge，无需 Python。

    打开下载页
  3. 连接你的电脑

    登录官网 → 我的设备 → 生成配对码。回到电脑设置输入配对码；配对码有时限，请使用当前官网生成的代码。

  4. 连接学校与设置目录

    在电脑设置打开学校登录窗口。完成登录后刷新课程，选择统一总目录或逐课程设置，也可粘贴完整路径。首次检查后回官网选择课程文件。

  5. 开始同步

    电脑开机联网且助手运行时执行任务。手机可下发任务，但不能运行 Windows 助手；浏览器关闭不影响助手运行。

连接电脑与设置引导

  1. 下载并运行助手

    完整解压 ZIP 后运行 CourseNestHelper.exe，保留 _internal 文件夹。

    下载 Windows 助手
  2. 在官网配对电脑

    我的设备 → 生成配对码 → 输入电脑设置。学校账号只在电脑上登录。

  3. 选择文件保存位置

    电脑设置顶部可选总目录或每课单独目录；支持浏览或粘贴路径。迁移时相同内容跳过，不同内容保留两份。

    打开电脑设置
  4. 官网统一管理计划

    设置中开启每日同步，助手负责执行。电脑离线时任务等待上线，旧计划冲突时先选择保留哪一个。
