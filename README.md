# iSpace 学习资料下载工具 · v0.1

在 Windows 本机用浏览器管理 BNBU iSpace 学习资料。为每门课程绑定专用目录，自动比对已有文件、下载新资料、保留老师更新后的版本。

## 当前状态

已实现本机网页、加密登录会话、Windows 凭据存储、课程绑定、内容去重、定时任务和模拟平台测试。公开登录页已核实为 Moodle 账号密码表单。**真实账号登录后的页面、教师身份识别及至少一门课程下载仍需本机验收**；未验收前不将此版本描述为完整验证过的学校适配，也不创建正式 `v0.1` 发布标签。

## 安装与启动

需要 Windows 10/11、Git、64 位 Python；推荐 Python 3.13。安装入口：[Python](https://www.python.org/downloads/windows/)、[Git](https://git-scm.com/downloads/win)。无需 Node.js、Docker 或单独的数据库服务。

1. 双击 `setup.cmd`。脚本在项目内安装 Python 3.13、虚拟环境和锁定版本的依赖，再下载 Playwright Chromium。首次需要联网，浏览器组件约数百 MB。
2. 双击 `start.cmd`，浏览器打开 **http://127.0.0.1:8765**。
3. 输入学校账号密码并点击“登录并记住”；有验证码时点击“手动登录窗口”，在弹出的浏览器内完成登录。
4. 点击“刷新课程”。为每门需要下载的课程选择已有文件夹，勾选同步并保存。每门课的目录必须独立，不能相互包含，也不能位于程序目录内。
5. 点击“立即检查”，查看新增、已存在和失败项目。
6. 开启“每日自动检查”，默认北京时间 20:00，保存计划。

程序关闭浏览器后继续在本机运行。`scripts/stop.ps1` 可停止网页服务；每日检查由独立的 Windows 任务计划执行，不依赖网页服务。若需停用每日任务，在网页取消勾选并保存。电脑关机时无法下载；补查需要电脑恢复开机、联网，且原 Windows 用户已登录。

## 文件行为

- 按平台课程 ID 记住目录，课程改名不会改变绑定。刷新课程时发现的新课程保持未绑定，提示用户选择目录。
- 每次递归扫描课程目录并计算 SHA-256。改过文件名、移动到课程子目录的相同内容也会被识别。
- 远端提供强 ETag 且本地对应内容仍存在时，不再次传输文件。远端校验信息不足时，临时下载到该课程的 `.ispace-temp` 目录进行内容比对；重复内容随即删除。
- 新增文件使用“原名_时间_短指纹.扩展名”，同名不同内容保留所有版本。既有文件不会被移动或覆盖。
- 本地删除了资料，下次检查会补下载；本地修改过资料时保留修改稿，并补充学校原版。
- 单次下载失败最多再重试三次；登录失败不循环尝试密码。页面读取失败、作者无法识别、网络错误均显示为未完成。
- 异常断电可能在 `.ispace-temp` 留下 `.part` 文件；它们不参与去重，可在任务停止后手动清理。

## 支持的学校资源

Moodle 课程中的文件、文件夹（包括嵌套文件）、教师的公告和讨论区附件，以及作业说明附件。支持课程和讨论分页、文件资源直接跳转及常见嵌入式附件。

课程列表使用登录会话可访问的 Moodle AJAX 接口，不需要管理员 Web Service token。论坛教师身份依据课程介绍中的教师联系人匹配；无法确认作者时报告未完成，不把学生附件当成教师资料。网站主题、插件或接口变化可能需要调整 `ispace/moodle.py`。未适配的页面不能通过测试数据代替真实验收。

本版不处理作业提交、测验答案、学生提交附件、外部网盘或流媒体下载。学校首页提示校外访问可能需要 VPN；以实际运行电脑的网络条件为准。

## 凭据与数据

- 学校账号密码存于当前用户的 Windows 凭据管理器，服务名 `BNBU.iSpaceDownloader.v0.1`；不写入 SQLite、日志或源码。
- 登录会话使用 Fernet 加密，密钥同样存于 Windows 凭据管理器；没有明文回退。
- 索引、任务状态、加密会话默认在 `%LOCALAPPDATA%\iSpaceDownloader`；可通过 `--data-dir` 或 `ISPACE_DATA_DIR` 修改。
- 网页只监听 `127.0.0.1`，校验 Host、Origin 和防跨站请求令牌，不使用第三方页面资源。
- “清除本机凭据与登录状态”会删除保存的密码及会话；不会删除课程文件和索引。
- 不要把学习资料目录添加到本项目的 Git 仓库。`.gitignore` 已排除运行数据、依赖、下载目录和常见凭据文件。

## 开发与测试

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ispace serve
.\.venv\Scripts\python.exe -m ispace sync
.\.venv\Scripts\python.exe -m ispace schedule --time 20:00
.\.venv\Scripts\python.exe -m ispace schedule --disable
```

网页与定时入口共用 `Service`、跨进程文件锁和同步引擎。SQLite 记录课程绑定、资源内容索引、任务和事件；文件真正落盘后才更新成功记录。

主要本地接口：`GET /api/state`；`POST /api/login`、`/api/login/manual`、`/api/courses/refresh`、`/api/sync`；`PUT /api/courses/{id}` 和 `/api/schedule`。写请求需要页面取得的 `X-iSpace-Token`。登录、读取课程和同步均异步执行，通过状态接口显示进度。

依赖锁在 `requirements.lock`，含跨平台条件和测试依赖。GitHub Actions 在 Windows / Python 3.13 上运行模拟测试，不接触学校账号或真实学习资料。

## 真实验收与发布

按照 `docs/ACCEPTANCE.md` 验证实际登录和课程资料。通过后创建 `v0.1` 标签并推送至 GitHub 私有仓库。使用 `git status` 检查每次提交内容，禁止提交账号密码、学习资料、会话或本地数据库。
