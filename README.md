# iSpace 学习资料下载工具 · v0.3 试用版

Windows 本机网页工具。选择课程，在课程浮窗中按 Week／课次浏览文件、预览内容，勾选需要持续同步的资料。

当前试用版本：`0.3.0.dev1`。稳定版 `v0.2` 保留。此分支用于首版体验和后续反馈，不创建正式 v0.3 发布标签。

## 开始使用

1. 首次安装双击 `setup.cmd`；已有 v0.2 环境直接双击 `start.cmd`，打开 http://127.0.0.1:8765/ 。无需新增软件或重新配置账号。
2. 左侧导航切换 **总览、我的课程、资料库、任务记录、设置**。刷新保留当前页面，支持浏览器前进／后退；手机点击“菜单”。
3. 在“设置”连接学校账号；“我的课程”点击“刷新学校列表”，再通过“添加课程”搜索并勾选课程。
4. 点击课程卡片打开浮窗。首次打开只读取学校文件清单；课程尚未绑定本地目录也能浏览。
5. 展开 Week／课次分组，搜索和勾选所需文件，点击“保存选择”。修改已使用整课模式的勾选时，会切换为“仅同步所选文件”，提示保存。
6. 下载前展开“课程目录与同步设置”，选择已有专用文件夹并保存。新课程首次绑定时默认勾选参与每日检查，可自行取消。
7. 点击“下载已选”。以后每日检查跟踪已选文件的更新，新发现文件等待你选择；也可切换“整门课自动下载”包含未来新增资料。

勾选草稿在同一浏览器标签页中暂存，刷新、搜索和展开分组不会丢失；点击“保存选择”后才持久写入本机数据库并影响每日任务。分组全选只包含当前清单中的文件，即使正在使用搜索过滤也是如此。

## 课程与资料管理

- 我的课程仅显示已加入课程，每门课为一个卡片，显示分组数、下载数量和同步模式。
- “移出我的课程”停止该课程同步，保留本地文件、分组目录和历史记录。刷新学校列表不会重新添加；可以通过添加课程恢复。
- 恢复课程保留旧目录和文件选择，每日检查保持暂停，需要在课程设置中重新开启。
- 资料库支持跨课程搜索文件名、分组标题和课程名，并按课程、分组及状态筛选。勾选“包含已移出的课程资料”可查找已移出课程的记录。
- 浮窗中选择状态与本地下载状态独立显示。取消勾选不删除文件；已选资料在学校清单中缺失时报告失败，不显示全部完成。
- 任务记录页分别展示下载事件与整理记录。部分失败、登录过期和不完整清单均有提示，旧清单和选择继续保留。

## 内容预览

支持 PDF、PNG／JPEG／GIF／WebP 图片和纯文本（如 TXT、Markdown、CSV、JSON）。Office、HTML、SVG 和可执行文件不直接渲染，可下载后在本机打开。

- 已下载资料优先预览通过指纹校验的本地文件。
- 未下载资料只有点击预览后才临时获取，并显示“临时预览，未保存到课程目录”。预览不改变选择和下载状态。
- 单文件预览上限 50 MB，文本最多显示前 1 MB。缓存保留最多 24 小时，启动或准备新预览时清理过期缓存；占用中的缓存留待下次清理。
- 正式下载时，远端强 ETag 与缓存一致且内容校验通过，可复用预览缓存。缺少可靠版本信息时重新获取校验。
- “下载此文件”是单次下载；若要持续跟踪更新，在课程浮窗中勾选并保存。
- PDF 使用浏览器自带阅读器，建议使用 Microsoft Edge 或 Chrome。

## v0.2 分类与文件保护继续保留

按学校章节及明确的 Week／课次标题分组；Lectures／Labs 大章节下的教师文件夹形成子分组。公共资料进入“课程公共资料”，无法确认的进入“待分类”，不按发布时间猜测教学周。

自动目录含顺序和名称，老师改名不会直接重命名本地目录。课程设置中的分组目录可以手动修改或恢复自动命名，各目录必须位于本课程内且互不包含。

旧资料整理、修改目录和调整归属均先预览、选择再确认。未匹配文件、修改过的内容和冲突文件保留原处。整理先复制并校验，再清理不再被引用的原件；只读属性保留到目标文件，中断可重试。

同组内容不重复保存，跨组优先复制本地内容。同名不同内容保留版本；缺失资料可补回。无可靠远端校验信息时可能临时下载核验。下载失败最多重试三次，密码失败不循环重试。

## 升级、账号和每日计划

沿用 Python 3.13、FastAPI、Playwright 与 SQLite，依赖仍由 `requirements.lock` 管理。新安装由 `setup.cmd` 准备环境；无需 Node.js、Docker 或云服务器。

升级前自动备份 SQLite 到原数据目录的 `index-pre-v0.3.sqlite3`。迁移可重复执行，已有绑定课程继续显示在我的课程中并保留整课自动下载行为，新添加课程默认仅同步所选文件。

账号密码和会话密钥仍在 Windows 凭据管理器，服务标识 `BNBU.iSpaceDownloader.v0.1` 保留。会话加密保存，数据库和运行状态默认在 `%LOCALAPPDATA%\iSpaceDownloader`，实际路径由 `.runtime/data-dir.txt` 固定，防止不同启动入口使用不同索引。

现有 Windows 任务 `iSpaceDownloader-v0.1` 保留，不重复创建或重设时间。当前本机设置为北京时间 **00:00**；全新安装默认 20:00。浏览器关闭后任务仍可执行，需要电脑开机联网且原用户已登录。

`start.cmd` 启动网页；`scripts/stop.ps1` 停止网页但不删除每日任务。取消每日检查请在设置页关闭并保存。

网页仅监听本机，写接口校验跨站请求令牌。预览仅接受数据库中的资料 ID，不接受任意路径或外部网址。学习资料、凭据、数据库、日志和缓存均不提交 GitHub。

## 开发与验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/check_ui_v3.py
.\.venv\Scripts\python.exe -m ispace serve
.\.venv\Scripts\python.exe -m ispace sync
```

浏览器验收脚本使用隔离的数据库、临时课程和模拟 API，不操作真实学习资料。GitHub Actions 在 Windows / Python 3.13 运行单元测试及浏览器流程。

新增接口：`PUT /api/courses/membership`（course_ids、added）；`POST /api/courses/{id}/catalog`；`PUT /api/courses/{id}/selection`（selected_ids、mode）；`POST /api/downloads`（course_id、material_ids）；`POST /api/materials/{id}/preview`；`GET /api/materials/{id}/preview` 和 `/preview/content`。资料查询新增 include_removed；状态接口返回课程统计及当前下载资料标识。

清单刷新、网络预览准备、同步、整理和配置修改共用任务锁。新增课程及文件选择 API 与原课程绑定、资料检索、整理预览接口兼容。

验证记录见 `docs/ACCEPTANCE-v0.3.md`；历史验收和发布记录保留在 v0.1／v0.2 文档与 Git 标签中。学校主题或附件结构变化仍可能需要适配。
