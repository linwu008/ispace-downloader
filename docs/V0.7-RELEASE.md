# BNBU CourseNest v0.7

## 本次可用功能

- 青蓝色界面与燕子归巢标识；首页说明目标、使用步骤、反馈联系方式；中英界面切换默认中文，课程原文保持不变。
- 官网是日常入口。跨页面保留原界面，等待超过半秒才显示加载提示。
- “我的课程 → 课程通知与要求”：提取网页文字、教师首帖通知、作业说明/日期、链接，以及能够确认的本人出勤与分组。按学校栏目与教学分组显示，保留来源、提取时间、改动历史。
- 不能完整识别的图片、嵌入内容或陌生插件标记为部分提取，提供学校原网页；没有 OCR，不读取学生讨论回复、个人提交或其他同学出勤。
- 私有学期存档无需补验邮箱。网站保存文字和文件索引，附件仍在电脑；学期切换、课程清空、解绑后保留档案。重新配对同账号且本机文件可校验时恢复关联。
- 导出由助手执行，ZIP 包含按学期/课程/教学分组排列的文件、课程说明 HTML 与历史、JSON 清单。缺失文件会标明部分完成；中途取消/失败不会删除原文件。
- 手机提交手动同步任务后先排队；电脑上线、学校登录和目录检查通过、空闲时才提示确认。官网或电脑设置均可确认。每日自动同步不额外要求逐次确认。
- 官网与助手独立版本。v0.6 及更早助手继续原同步，新功能需要一次升级到 v0.7。此后支持自动检查、一键升级和可选空闲自动安装；校验 Ed25519 签名及 SHA-256、保留原版本、启动失败回退。

## 当前边界

不激活 R2，不绑定付款方式，不新增收费服务。云端原文件、分享、迁移、AI 总结、邮件验证/找回密码保持关闭。手机下单不意味着文件已上传云端。电脑本地文件丢失且没有其他备份时无法恢复。

标准 Moodle Attendance 的本人报告有专门解析；学校自定义的出勤/分组插件仍需实际页面结构验证，不把未知页面标为完整识别。网站显示的提取时间不是学校最后修改时间。

本地学期目录持有稳定档案 ID 和校验后的文件引用，复用原课程文件，不另外复制一整份。课程文字平时仅在内存中提取后发送到本人网站账号，只有主动导出才写入 ZIP。

## 兼容、存储与发布

- `study_archives` / `study_files` / `study_notes` 是本次统一索引，档案 ID 不依赖助手材料表编号。位置通过设备归属解析；未来云迁移沿用这些 ID 和接口，增加对象位置/校验状态，不把存储商端点下发给助手。
- `0003_v07.sql` 为纯新增表、索引和触发器。Worker 的幂等首次初始化由同一 SQL 生成，在一次事务中执行并记录版本；并发首次请求可以重入。原账号、配对、任务表不重写。代码回退保留新表，不删存档。
- 新助手上报 `confirm-v1`、`notes-v1`、`local-archive-v1`、`update-v1`；旧助手仍支持原有任务。最低版本仅由明确的 `MIN_HELPER_VERSION` 控制，原因由 `HELPER_UPDATE_REASON` 提供，官网版本变化本身不触发升级。
- 默认个人课程文字（含历史）500 万字符、全站 1 亿字符，数据库事务内计数防止并发绕过；可用 `NOTE_TEXT_LIMIT` / `GLOBAL_NOTE_TEXT_LIMIT` 配置。文件索引软上限 `NOTE_FILE_LIMIT=20000`。重复清单跳过发送，批量 SQL 减少免费数据库请求。
- 原 v0.5 云存储接口仍受服务端关闭开关控制，不提供另一套用户工作台。接云服务前仍需核实额度、费用及迁移验收，不能只迁移目录便声称文件已迁移。
- 更新签名私钥只在忽略目录 `.runtime/release-signing.key`，公开包和仓库只包含公钥。丢失私钥时恢复私有备份，不静默换钥。Ed25519 包签名不等于 Windows Authenticode；EXE 尚无 Windows 发行者签名。
- 英文词典和标识以 `cloud/public` 为唯一编辑源，打包脚本同步到助手，避免多份文案分别维护。

## 验收范围

本地验收：136 项 Python 测试、28 项 Node 测试，v0.3–v0.7 五组浏览器回归，实际冻结 EXE 验收，以及 Workers 本地运行时/D1 的批量入库与初始化通过。新增测试覆盖原文保留、本人出勤隔离、教师身份限制、签名篡改、危险 ZIP 路径、导出缺失/取消、Windows 真实回退脚本、旧助手、任务确认、历史额度原子性、解绑与重新配对权限、跨学期目录迁移和旧快捷方式升级跳转。

仍不能代替另一台真实 Windows 电脑和学校自定义插件的现场验收。上线后应先小范围确认实际课程页面与升级体验。
