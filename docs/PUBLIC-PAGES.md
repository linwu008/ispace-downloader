# 产品首页与独立登录页

- `/` 为产品首页，登录后仍可查看介绍；顶部入口自动变为“进入学习空间”。
- `/login.html` 处理现有账号的登录、注册与首次使用引导，沿用原账号接口与邀请码配置。
- `/workspace.html#/overview` 为学习空间。旧的 `/#/...` 书签与助手链接自动进入对应工作台页面。
- 工作台内的存档、下载及账号页面继续保留同一文档导航，返回时保留设置草稿、原页面与滚动位置。
- 账号失效后跳到独立登录页；登录成功只允许回到已知的工作台栏目。恢复已有会话期间不显示密码表单，网络失败提供重试。
- 首页与登录页共用 `public-site.css`、`public-site.js` 和原有中英翻译模块，工作台样式独立；演示稿仍在 `design/home-login-demo/`，不进入生产资源包。
- 网站版本仍为 v0.7，助手与通信接口不变，不需要重新下载安装。

验收：`scripts/check_ui_public.py` 覆盖真实本地注册/登录、8 位密码、错误提示、登录恢复不闪表单、旧链接、访客、中英切换和移动端布局。原 v0.4–v0.7 浏览器回归继续覆盖同步、配对、任务、存档及返回状态保留。

本次不修改数据库、服务配置或付费服务开关。
