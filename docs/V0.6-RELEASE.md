# BNBU CourseNest v0.6

## 新增与改进

- 访客演示：无需注册，提供示例课程、文件、任务、计划及目录操作；全程提示模拟，真实服务仍需登录。
- 官网作为日常入口，顶部“连接电脑 / 设置引导”提供下载、配对、学校登录、目录设置完整步骤。注册后自动展示引导。
- 计划统一由官网设置。助手升级后关闭原 Windows 每日任务，保留原时间；冲突由用户选择。离线任务上线后执行。
- 待执行任务可直接取消，运行任务需助手确认停止。清理未完成下载、保留已完成资料。旧助手仍可同步，运行取消需升级。
- 电脑设置顶部提供保存位置：总目录 / 逐课程两种方式，支持粘贴路径、检查权限和前置文件夹窗口。
- 更换目录可选择后续生效或迁移已下载文件；按内容校验去重，同名不同内容保留两份。
- 复用既有原子复制和数据索引逻辑，集中取消控制与目录设置，减少重复实现。

## 升级说明

先等待任务完成或取消并等电脑确认，从托盘退出旧助手；完整解压 v0.6 包并运行。原账号、配对、目录和已下载文件保留。首次会让你确认保存方式。

官网无需重新注册。手机可演示、管理计划和任务，学校登录及本地目录设置需在电脑完成。

## 服务边界

R2、邮件与 AI 仍关闭，不新增付费服务。资料目前保存到电脑；学期存档、找回密码、邮件验证和知识总结暂未启用。

此版本无需新的生产数据库表迁移。源码仓库保持私有，公开仓库仅分发独立 Windows 二进制包和校验值。安装包暂未代码签名。

## 验收与安装包

本地通过 120 项 Python 测试、21 项云端测试、v0.3–v0.6 浏览器回归及实际 EXE 启动验收。访客演示流程没有真实业务 API 请求。
