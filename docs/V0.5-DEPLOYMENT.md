# v0.5 部署与验收

## 当前交付边界

代码、本地迁移、账号恢复、存档、知识总结、受开关控制的问答和助手已实现。只有完成下列外部配置和真实服务验收后，才能把 v0.5 标记为正式发布。不要直接推送到当前 Cloudflare 自动部署分支来绕过这些步骤。

## 服务配置

1. 备份现有 D1 `coursenest`，运行增量迁移 `0002_v05.sql`。原有用户、设备及任务表不清空。测试环境使用独立数据库。
2. 在 Cloudflare 创建私有 R2 桶，分别绑定 `ARCHIVE_BUCKET`（课程原文件/文字）和 `DOWNLOAD_BUCKET`（助手包）。桶不直接公开；下载经 Worker 权限检查。开通若要求付款方式或付费订阅，先由项目所有者确认，不能自动升级。
3. 在 Worker 添加 `AI` Workers AI 绑定。默认模型 `@cf/qwen/qwen3-30b-a3b-fp8`，保持 Workers Free；生产 `QA_ENABLED=0`。模型若不可用需核实替代模型价格，不自动转付费。
4. 在 Resend 验证发信域名 `bnbucoursenest.cn`，配置 DNS 验证记录。把 API 密钥写入 Worker Secret `RESEND_API_KEY`；`MAIL_FROM` 使用已验证域名的发信地址。不要放入 Git、截图或普通变量。
5. 保留现有 `INVITE_CODE` Secret、`PUBLIC_ORIGIN` 和自定义域名。`INVITE_REQUIRED=1`，以后开放注册改为 `0`。

## 安装包公开分发

上传 `dist/CourseNestHelper-0.5.0-windows-x64.zip` 到 DOWNLOAD_BUCKET，生成 `release.json`：

```json
{"version":"0.5.0","key":"CourseNestHelper-0.5.0-windows-x64.zip","sha256":"实际安装包 SHA-256"}
```

官网 `/download.html` 读取元数据，`/api/helper/download` 流式返回安装包，不要求登录或 GitHub 权限。下载无需访问源码仓库。必须先确认安装包校验值和下载成功，再开放新用户。

## 默认额度与扩展

- 用户存档 250,000,000 字节、全站 8,000,000,000 字节、原文件最多 50,000,000 字节。
- 每次上传为文本额外预留 1 MB，完成后按实际文字字节记账；并发请求不能跳过预留。临时对象过期后定期删除。
- AI 日预算默认 8,000 Neurons，预留输入和输出上界；服务商 10,000 的免费额度由账号共享。超额任务继续排队，不自动付款。
- 发信保留余量：最多 90 封/日、2,700 封/月（应用控制），验证/找回另按用户限速。
- 套餐字段 `account_profiles.plan` 默认 trial；存储、模型、问答和邀请限制均为可配置接口，v0.5 无支付和收费逻辑。
- 服务商免费额度不是硬费用保证；其他应用的账号共享用量、对象临时空间、下载次数和服务商计价也须在真实上线前核对。

## 验收与回退

运行 Python 全部测试、Node 全部测试、check_ui_v3/v4/v5、build_assistant 和 check_bundle。另需实际验证 Resend 邮箱送达、R2 上传下载、AI 多语言总结质量，以及另一台 Windows 电脑首次安装。

上线顺序：测试环境 → 真实外部服务验收 → 备份/生产迁移 → 新官网与安装包 → 小范围升级 → v0.5 release。保留 v0.4 包和部署；回退代码时保留新增数据表与对象，不执行删除迁移。

兼容：旧助手继续原有同步，新存档要求 archive-v1 能力。现有账号可以继续登录，新增存档/分享须补验邮箱。原始学校账号、目录和配对数据不搬迁、不重置。
