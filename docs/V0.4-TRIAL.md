# 首版本机验收记录

本版产品名为 **BNBU CourseNest（课巢）**。独立网站管理产品账号、设备、课程选择和任务；Windows 助手主动向网站获取任务并在本机执行。没有内网穿透、远程任意命令、学校密码云端保存或学习文件上传。

## 本机体验

使用项目根目录 `start-v04.cmd` 同时启动网站和原有助手。

- 网站：`http://127.0.0.1:8787`
- 本地助手：`http://127.0.0.1:8765/#/settings`
- 在网站选择“创建账号”，使用自己的产品邮箱和至少 12 位密码。
- 本机开发邀请码：`NEST-LOCAL-04`（只用于本机环境，正式部署必须另设私密邀请码）。
- 网站“我的设备”生成配对码，在助手“连接 CourseNest”填写网站地址与配对码。
- 现有学校登录、课程目录、文件、历史与每日任务保持原样，不会自动上传文件内容。配对后才开始上报课程与状态。

邀请码仅用于控制首版体验范围，不代替账号隔离。首版每个账号一台电脑，暂不提供邮箱验证、密码找回、设备多开、自动更新或公开注册。

## 可验收流程

1. 未配对时，显示引导与空列表，不能下发下载任务。
2. 配对后，在我的课程查看原有课程与分组，清单来自该电脑。产品网站“刷新学校列表”只更新列表；“更新资料清单”只读取资料，不自动下载。
3. 在两个 Week 中选择文件，保存并同步。网站任务记录依次显示等待、进行、成功/部分完成/失败；未选文件保持未下载。
4. 再次同步，相同内容不重复保存。更新保留版本、同组去重和跨组本地复用沿用 v0.3 引擎。
5. 关闭/离线助手后在网站下发任务，恢复运行后自动执行。在本地设置暂停接收网站任务后，任务保持等待。
6. 修改选择但不保存，等待自动刷新或刷新页面再打开课程，草稿保留。切换产品账号不会共享草稿。
7. 从网站移出课程，停止同步但保留文件与绑定；添加时可恢复。
8. 文件“查看位置”显示电脑上的课程/分组及路径；内容预览、目录授权和资源管理器定位继续在本地助手完成。
9. 网站解除设备后旧令牌立即拒绝访问，其他账号看不到该账号课程、文件名、任务或设备信息。

## 实现与限制

- 网站部署目标：Cloudflare Workers 静态资源 + API + D1 + Cron。今晚只运行同一 Worker 代码的本机 Node SQLite 适配器；没有开通服务、购买域名或向 Cloudflare 部署。
- 本机 SQLite 云数据库位于 `.runtime/cloud-v04.sqlite3`；助手沿用原有数据目录。全都被 Git 忽略。
- 网站登录使用服务端会话、HttpOnly/SameSite Cookie、CSRF 校验、PBKDF2 密码散列及接口限流。设备使用一次性配对码和可撤销的加密本地令牌。
- 任务具有租约、心跳及本地执行回执。网络丢失确认后重发不会再次执行已经有回执的任务；进程中途退出时依靠原有内容校验保证再次同步去重。
- 当前清单上限为 500 门课程、3000 个分组、10000 个资料关联；超过上限或请求大小限制时明确报错，不视为同步成功。大规模清单分页上报、邮件验证、账号删除/数据保留策略与公网性能需要后续完善。
- 浏览器自动验收使用模拟学校和临时文件，覆盖真实 HTTP 的网站→助手→下载链路；不意味着已在 Cloudflare 真机、不同物理电脑或真实学校账号下完成公网验收。

正式域名接入、真实公网验收及正式 v0.4 标签，在用户验收后进行。
