# BNBU CourseNest Windows 同步助手 · v0.7

## 首次使用

1. 在 https://bnbucoursenest.cn/download.html 下载安装包。完整解压 ZIP，保留 `_internal` 文件夹；运行 `CourseNestHelper.exe`。
2. 支持 Windows 10/11 x64，需要 Microsoft Edge，无需 Python 或 Node.js。
3. 登录官网，在“我的设备”生成配对码，在弹出的电脑设置页面输入。学校账号与官网账号不同。
4. 在电脑设置中打开学校登录窗口，登录后刷新课程，在顶部选择统一总目录或每门课程单独设置。支持浏览文件夹，也可粘贴完整路径并点击“检查路径”。
5. 回到官网管理课程、同步和任务。官网是日常使用入口。

## 运行与升级

- 关闭浏览器不会停止助手。电脑须保持开机、联网；右下角托盘菜单可进入电脑设置或退出。
- 托盘可选择 Windows 登录后启动。运行目录改变前先关闭该选项。
- 升级前等待任务完成，从托盘退出旧助手，再运行新版。同一时间只运行一个助手。
- 独立包保留 `%LOCALAPPDATA%\BNBUCourseNest` 的账号和配对数据；源码版继续使用既有配置目录，两者不会自动搬迁数据。
- 本地地址 `127.0.0.1` 始终指当前电脑。网页按钮不会自动安装或启动 EXE。

## 学期存档与课程文字

- 官网“学期存档”先确认学年、学期，再更新课程资料清单或同步。通知、作业要求、截止时间、可识别的本人出勤及分组保存在网站，默认仅本人可见。
- 课程文字保留改动历史；图片、扫描内容或不能确认归属的页面标注“未完整提取”，请核对学校原网页。不会上传其他同学的出勤表或个人提交。
- 原附件保留在电脑的课程目录，按学期建立引用目录，复用已有文件，不额外复制或下载一份。清空 iSpace、移出课程或解除配对不删除本地文件与网站旧档案。
- “导出到电脑”生成包含学期、课程文件、目录和课程文字历史的 ZIP。电脑准备好后确认；文件缺失时明确报告部分完成。原文件被自行删除且没有其他备份时无法恢复。
- 本地索引位于数据目录的 `semester-archives`，导出位于 `exports`。以后可接云存储，但当前不提供远程原文件下载、分享或云端备份。
- R2、AI、邮件仍关闭；不生成 AI 总结、不发送验证及找回密码邮件。

## 官网和助手独立更新

v0.6 及更早助手需要一次手动换到 v0.7，才能使用课程文字、学期存档、任务确认和后续自动升级。等待任务结束，从托盘退出旧助手，完整解压并运行新包；不要删除账号数据或课程文件。

从 v0.7 起，在电脑设置中检查更新并点击“升级助手”；默认只检查，可选择空闲时自动下载安装。更新核对官方来源、Ed25519 签名和 SHA-256，旁路安装新版本，启动检查失败则恢复原版本。账号数据仍使用原目录。官网更新本身不会要求更新助手；必要的新电脑功能才提示升级。

手机提交的手动同步任务先排队。电脑联网、学校登录有效、课程目录可写且空闲后，官网提示确认；也可在电脑设置确认。电脑提示可以关闭，官网提示默认开启，已关闭的一批提示不会反复弹出。每日自动计划继续按官网设置执行。

当前安装包未做 Windows 代码签名。请核对官网下载页提供的 SHA-256。

## v0.6 计划、取消与目录

- 每日计划统一在官网“设置”。升级会停用原电脑每日任务并保留时间；如果两边时间不同，官网会请你选择保留哪一个。电脑离线时等待上线补执行，保持助手运行。
- “任务记录”可取消待执行或运行中任务。运行中显示“取消请求已提交”，直到电脑确认停止；离线时不能立即确认。当前未完成下载会清理，已完成文件保留。
- 首次选择总目录后，后续课程按课程名称和编号创建子目录；仍可单独修改某门课程。
- 更换目录时可选择只影响后续下载，或迁移助手记录的文件。相同内容跳过，同名不同内容保留两份；复制校验成功后才清理原文件。磁盘故障时原文件保留，请重试。不要在迁移过程中退出助手。
- 官网可直接进入访客演示，所有数据和动作均为模拟，无法使用真实同步或文件功能。注册后的“连接电脑 / 设置引导”可随时重新打开。
