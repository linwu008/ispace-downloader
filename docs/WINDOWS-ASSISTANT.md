# BNBU CourseNest Windows 同步助手 · v0.4 正式版

## 首次启动

1. 将整个 ZIP 解压到固定目录，例如 `D:\Apps\CourseNestHelper`。不要只复制 EXE，也不要直接在 ZIP 内启动。
2. 双击 `CourseNestHelper.exe`。无需另装 Python、Node.js 或数据库；电脑需要 Windows 10/11 x64 和 Microsoft Edge。
3. 浏览器会打开 `http://127.0.0.1:8765/#/settings`。在本地助手中登录学校账号、添加课程并绑定本地目录。
4. 登录 CourseNest 产品网站，在“我的设备”生成配对码，将网站首页地址和配对码填入本地助手“连接 CourseNest”。配对码 10 分钟内有效，只能使用一次。
5. 回到网站选择课程、更新资料清单、勾选文件，然后“保存并同步”。助手约每 15 秒领取任务，网站约每 5 秒更新显示。

正式网站地址为 `https://bnbucoursenest.cn`，已是助手默认地址。配对码须在该网站生成；本机测试站 `http://127.0.0.1:8787` 的码不能混用。注册邀请码与设备配对码是两回事。

网站账号与学校账号相互独立。学校账号密码、会话和学习文件留在本机；网站保存课程、分组、文件名、保存位置、选择及任务状态。文件内容预览和资源管理器定位在本地助手中进行。

## 后台运行

- 关闭浏览器不会关闭助手。右下角绿色托盘图标可重新打开界面或退出。
- 可在托盘菜单勾选“Windows 登录后启动”；仅修改当前用户的启动项，默认关闭。开启后不要移动程序目录；如需移动，先取消勾选，再在新位置开启。
- 网站每日计划要求助手保持运行、电脑开机联网。离线后恢复会补查，重复积压的每日检查会合并。
- 原有 iSpace Windows 每日任务继续保留。如果它已启用，需要在本地设置中关闭后才能开启网站计划；两个计划不重复创建。
- 任务执行中不能从托盘退出，等待完成后再试。断网重试与文件完整性由现有同步逻辑处理。

## 数据和升级

新安装助手将数据库与加密配置保存到 `%LOCALAPPDATA%\BNBUCourseNest`，文件仍进入你授权的课程目录。凭据保存在 Windows 凭据管理器，服务标识沿用 v0.1。

已有源码版用户继续使用项目启动脚本，保留 `.runtime/data-dir.txt` 指向的数据目录；不要把空白的新安装目录当作原有数据库。首次添加 v0.4 表前生成 `index-pre-v0.4.sqlite3` 备份。源码版与独立包共用 8765 端口，同一时间启动一个即可。

在本地断开配对会停止接收任务；在网站解除设备会撤销设备令牌并清除该设备清单，已下载文件保留。重新配对可使用同一所选目录。

试用包尚未签署 Windows 代码签名证书。安装包只包含代码和运行依赖，不包含开发者账号、数据库或学习资料。正式分发前还需完成真实公网与其他电脑验收、签名及更新机制。
