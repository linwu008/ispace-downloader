# v0.1 本机验收

公开登录页已确认存在 `username`、`password` 和 `logintoken`；浏览器登录会沿用网站表单令牌。随后已在本机确认真实账号登录成功，课程接口读取到 10 门课程，一门课程识别到 12 个附件链接且无解析错误。还没有保存课程目录绑定，尚未实际下载文件。

实施期间模拟测试已覆盖课程隔离、嵌套已有文件、同名更新、改名和删除后的恢复、弱 ETag 内容校验、磁盘写入失败重试、登录失效、分页、附件类型、异常附件、凭据加密、任务互斥及定时任务 XML。

以下项目必须由本机真实环境完成，未完成时保持未勾选：

- [ ] 使用真实账号登录成功，重启网页后登录状态仍可使用。
- [ ] 读取完整课程列表，并与学校“我的课程”页面对照。
- [ ] 为至少一门课程绑定专用文件夹，首次检查完成，下载文件能够正常打开。
- [ ] 连续检查两次没有重复成品文件；有可靠 ETag 时没有重复文件传输。
- [ ] 与学校页面对照文件、文件夹、公告／讨论区及作业说明附件的数量；若本课无某类附件，则记录为未验证并另选课程测试。
- [ ] 教师识别正确；不明作者和未适配页面显示失败详情。
- [ ] 删除一个由本程序下载的测试文件后，可自动补回。
- [ ] 两门课程绑定不同目录时，不混放资料。
- [ ] 启用 Windows 每日任务，确认任务存在、时间正确，使用任务计划程序“运行”后能生成同步记录。
- [ ] 错过计划执行时间后恢复开机联网和用户登录，确认能补查。
- [x] GitHub 私有仓库已推送，GitHub Actions 的 Windows / Python 3.13 模拟测试通过（37 项）。

额外完成：Windows 计划任务 XML 已通过实际注册及 Python 动作执行验证；独立测试任务已删除，正式每日任务尚未启用。

完成以上适用项目后再运行：

